# Onboarding epic

Pharmacy registration → home → complete profile.

Edit the screen folder:

- Markup: `<screen>.html`
- Unique styles: `<screen>.css`
- Unique behavior: `<screen>.js`

Complete-profile tabs, dropdowns, and document sheet are shared in `shared/`. AI verify + lock live in `complete-documents/`.

`screens.js` is the stepper order. `index.js` binds every onboarding screen when the active phone screen changes.
